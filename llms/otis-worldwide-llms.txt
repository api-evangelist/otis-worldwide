# Otis Worldwide

> Otis Worldwide is the world's largest manufacturer, installer and servicer of elevators,
> escalators and moving walkways, operating in more than 200 countries and territories. Its
> connected-building software portfolio — Otis ONE IoT monitoring, the Compass destination-entry
> dispatch platform, eCall and eView — is exposed to integrators through two named API products
> behind the Otis Developer Portal.

Generated by API Evangelist on 2026-08-28 from public Otis sources. Otis does not publish an
llms.txt of its own (https://www.otis.com/llms.txt and https://developers.otis.com/llms.txt both
return 404). This file is a faithful summary of what Otis publishes publicly — it is not an Otis
document and it does not stand in for the gated reference.

## What an agent can and cannot do here

- There is NO public machine-readable contract. No OpenAPI, AsyncAPI, GraphQL SDL, WSDL, .proto or
  Postman collection is published at any Otis URL that was probed.
- The developer portal (Azure API Management) shows ZERO APIs to an anonymous caller. The API
  catalogue, reference, error semantics and reversal operations are all behind a portal account
  plus a subscribed API product.
- API access is contractually tied to Otis holding the elevator maintenance contract at the site.
  There is no self-serve path from reading this file to calling the API.
- The write operations these APIs expose move physical elevators. No cancel/undo operation and no
  reversal window is published. Do not assume one exists.

## APIs

- [Otis Integrated Dispatch (OID) API](https://www.otis.com/en/us/products-services/products/otis-integrated-dispatch):
  cloud-based or on-premise API for integrating service robots with Otis elevators. Otis's own data
  sheet lists the available operations as: place a hall call; place a car call; place a destination
  call; get car and door info (car position, direction of travel, load, door status, car mode);
  metadata about the building and elevators; authentication. Protocol: secure websockets.
- [Otis Building Management API](https://www.otis.com/en/us/building-management-api): moves elevator
  and escalator data into BMS, BAS and SCADA platforms — real-time status, alerts, min/max/average
  waiting times, calls by source and destination, trip starts and destinations — and accepts
  operational commands: hall calls, car calls, operating modes, alarms, scheduled floor lock-outs,
  priority calls and emergency modes including security lockdown.
- Otis eCall Pro API: named in Otis's published "Otis eCall Pro API and OID API Appendix". No public
  technical documentation was found.

## Authentication and transport

- Authorization: OAuth 2.0, client-credentials flow, using a client-id and client-secret.
- Portal subscription key required for further operations once an API product is subscribed.
- Protocol: secure websockets. Encryption: TLS 1.2; data encrypted at rest and in transit.
- Traffic throttling: Otis states "None" for the OID API. No numeric quota, window, burst allowance
  or rate-limit response header is published.
